# Sources and attribution

This index tracks the research used in the talk. Exact links, publication dates, slide mappings, and access dates will be finalized before the deck is published.

## Build and review

- Sackman, Erikson, and Grant (1968) — exploratory study associated with the programmer-performance variance discussion.
- GitClear, *AI Assistant Code Quality Report* (2025) — changes in refactoring and code duplication across 211 million changed lines.
- GitHub activity and Octoverse data — pull-request volume and platform activity.
- StrongDM, software-factory writing — self-reported token expenditure of up to $1,000 per engineer per day.
- Godot Engine maintainer policy — restrictions on autonomous AI-generated contributions.
- Zig maintainer commentary — review as an investment in contributors rather than only code diffs.
- curl maintainer commentary — low-signal and AI-generated vulnerability reports overwhelming useful review capacity.

## Break and operations

- METR randomized controlled trial (2025) — experienced open-source developers' perceived speedup versus measured completion time when using AI tools.
- Anthropic skill-formation research (2026) — AI assistance, comprehension, and debugging performance.
- Cortex engineering benchmarks — change-failure and incident signals.
- CodeRabbit analysis — review findings in AI-authored versus human-authored pull requests.
- AWS DevOps Agent, Dynatrace Davis AI, and Datadog Bits AI SRE — examples of AI-assisted operational investigation.

## Defend

- Veracode, *GenAI Code Security Report* (2026) — security results across model-generated coding tasks.
- Black Duck, *Open Source Security and Risk Analysis* (2026) — vulnerability prevalence and mean vulnerabilities in audited codebases.
- Boost Security, TeamPCP, Aqua Security, and Microsoft Defender reporting — compromised GitHub Actions and associated defensive guidance.
- Data Center Watch (2026) — data-centre construction opposition and delay estimates.
- Game Developers Conference, *State of the Game Industry* (2026) — industry sentiment toward generative AI.

## Grow and close

- Sonar, *State of Code Developer Survey* (2026) — AI-authored committed code, developer trust, verification, and validation time.
- Craig Shyjak's LinkedIn post series — original commentary and examples that informed the talk.
- Prairie Dev Con 2026 keynote listing — event context and speaker information.

## Original framing

The talk's central synthesis—generation becoming cheap while judgment, ownership, and accountability remain scarce—is the speaker's original framing, not a third-party statistic.
