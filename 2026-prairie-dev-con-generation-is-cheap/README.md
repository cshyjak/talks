# Generation Is Cheap. Judgment Isn't.

**Prairie Dev Con Winnipeg 2026**  
**Craig Shyjak**

## Talk summary

AI did not make software free. It moved the constraint from typing code to judgment, review, debugging, trust, and accountability.

This keynote examines the middle of that transition through four lenses:

1. **How we build** — review becomes production.
2. **How we break** — understanding becomes scarce.
3. **How we defend** — trust boundaries become explicit.
4. **How we grow** — judgment becomes the career.
